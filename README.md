# SwingSnap

Free, ad-free, no-signup tempo practice for full swings (wedge, iron, driver).
Pick a total time and a backswing:downswing ratio, press start (or just lay the phone flat), and swing to the rhythm.

- 2-beat (start, impact) or 3-beat (start, top, impact) sound patterns
- Full-screen bar, traffic light for the next swing, red flash at the transition
- Swing interval: non-stop, 3, 5 or 8 s
- "Make my tempo": own time and ratio, up to 5 saved on the device
- English / 日本語 / 한국어. Works offline. No data leaves the phone.

## Download (Android)
Get `swingsnap-debug.apk` from the [Releases](../../releases) page, open it on the phone and allow installing from this source.
This is a test build, not a Play Store release.

## Run in a browser
`python -m http.server 8765`, then open `http://localhost:8765/` (phone layout).

This is a practice rhythm, not a measurement or coaching tool, and it makes no promises about distance or accuracy.
